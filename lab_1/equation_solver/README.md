# Решатель уравнений

Лабораторная работа по ООП, вариант 2. Консольное приложение на C++20
для решения линейных и квадратных уравнений с комплексными коэффициентами.

Меню позволяет добавлять уравнения, находить корни, вычислять значения
в заданной точке и искать уравнения с указанным корнем.
Комплексные числа вводятся двумя числами через пробел: действительная
и мнимая части, например `2 -3` для `2 - 3i`.

## Сборка

Готовая версия для Windows x64 доступна в разделе
[Releases](https://github.com/DomDomych/eqsolver/releases).
Распакуйте ZIP и запустите `run.cmd`. Для запуска тестов используйте `tests.cmd`.
Устанавливать компилятор, CMake или GoogleTest не нужно.

Нужны CMake 3.16 или новее и компилятор с поддержкой C++20.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Запуск на Linux: `./build/eqsolver`.
На Windows при сборке через Visual Studio: `.\build\Release\eqsolver.exe`.
При использовании MinGW: `.\build\eqsolver.exe`.

## Скрипты для Linux

```sh
./scripts/build.sh         # Сборка Debug
./scripts/build.sh Release # Сборка Release
./scripts/run.sh           # Сборка и запуск
./scripts/test.sh          # Сборка и запуск тестов через CTest
./scripts/format.sh        # Форматирование C++ файлов (нужен clang-format)
```

Скрипты сборки, запуска и тестирования принимают `Debug` или `Release`.
Сборки сохраняются в `build/Debug` и `build/Release`.
Модульные тесты используют GoogleTest. CMake ищет установленную библиотеку,
а при её отсутствии скачивает закреплённую версию (для первой сборки нужен интернет).
Запуск: `./scripts/test.sh` или `ctest --test-dir build/Debug --output-on-failure`
(для второй команды нужен CMake 3.20 или новее).
Тесты можно отключить при конфигурации: `-DBUILD_TESTING=OFF`.

## Структура

- `core/` — комплексные числа, уравнения и коллекция.
- `cli/` — консольное меню и обработка ввода.
- `main.cpp` — точка входа.
- `tests/` — модульные и интеграционные тесты.
